# 小小焗烤師

一個繁體中文、可在瀏覽器直接遊玩的料理學習遊戲原型。跟著場景逐步完成一人份義式繽紛焗烤麵，學習秤量、備料、汆燙、煮麵與焗烤。

## 本機遊玩

直接用瀏覽器開啟 `index.html` 即可，不需安裝套件或建置工具。

## 發布

推送到 `main` 分支後，GitHub Actions 會自動把網站部署到 GitHub Pages。部署完成後，可在 repository 的 **Settings → Pages** 查看網站網址。

## 食譜來源

遊戲使用臺南市政府衛生局《義式繽紛焗烤麵（一人份）》作為示範食譜。遊戲中的步驟操作是互動教學模擬；實際烹調請依食譜、烤箱說明與安全指引操作。

- [臺南市政府衛生局健康報（2019 年 6 月）](https://health.tainan.gov.tw/lasthealthweb/warehouse/%7B8CECF083-CBD2-4017-AA26-5A4868AD2E88%7Dfile/lizi/108/108%E5%B9%B406%E6%9C%88%E5%81%A5%E5%BA%B7%E5%A0%B1.pdf)
